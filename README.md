# gera

AI が生成した Markdown 文書を、読んで、直して、書き戻すためのデスクトップアプリ。

## 名前について

ゲラとは校正刷りのこと。組版を終えて刷り上がり、これから読み合わせて赤を入れる紙を指す。

AI の出力はゲラである。すでに形になっていて、体裁も整っている。しかし、そのままでは出せない。

## 何を解こうとしているか

既存の Markdown エディタは「自分で書く人」向けに設計されている。しかし AI が書いた文書を扱うとき、実際の作業はこうなる。

- 読む時間が、書く時間より長い
- 主な操作は、追加ではなく削除と並べ替えである
- ファイルを開くのではなく、貼り付けから始まる

gera はこの用途だけに最適化する。汎用のエディタは目指さない。

## 二つのモード

同一画面を切り替える。

| モード | 表示 | 対応する作業 |
|---|---|---|
| 閲覧 | 完全に描画する。表も画像も図も | 読み合わせ |
| 編集 | 記法を残したまま装飾のみ当てる | 赤入れ |

閲覧モードは明朝、編集モードはゴシックで組む。モードの状態を、本文そのものが示す。

本文以外の常設 UI は持たない。

## 技術

- **Tauri** — アプリ基盤
- **CodeMirror 6** — エディタコア
- **TypeScript** — ロジックの大半

Rust 側の責務はファイル入出力、ダイアログ、ウィンドウ状態の保存のみ。
